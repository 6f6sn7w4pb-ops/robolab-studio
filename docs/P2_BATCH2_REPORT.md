## 操作方法

关闭旧窗口后按原方式启动。Windows 启动器仍然进入 WSL 项目，不需要重建环境。

1. 在右侧“机械臂控制”中向下滚动至“末端 XYZ 点动 · 世界坐标 / mm”。设置 1–10 mm 步长，点击 X−/X+、Y−/Y+、Z−/Z+。保持命令发出时的末端朝向；坐标轴属于 MuJoCo 世界坐标系，不是相机或夹爪坐标系。
2. 编辑模式直接更新机器人姿态和最近的重置基准，仿真物体的自由关节位置不会随点动修改。仿真模式只设置关节目标，需要“启动物理仿真”或“单步 +20ms”推进运动。物理运动继续使用原有 0.6 rad/s 目标限速及限幅 PD；不能把界面目标接受理解成已经到位。
3. 点动反馈区分空闲、等待运动到达、已到达和超时保持。尚有未完成的点动／关节目标时拒绝叠加点动；3 秒仿真时间内未到位则保持当前关节。规则／Mock／VLA 执行期间，包括暂停后，须先“结束策略”才能点动。后端同样执行互斥校验。
4. 中央选择“P2 记录 / 状态查看”，默认浏览 `outputs/p2_grasp/`。本批验收记录位于 `outputs/p2_batch2/episodes/`，可用“选择记录根目录”切换到该目录，再“刷新记录”。新记录正常执行后仍保存到默认目录。
5. 选择记录可见原始任务、seed／官方初态、状态、样本数和原始接触／提升／官方判定。✓ 表示真，✗ 表示假，? 表示未提供。状态分别为成功、失败、已取消、不完整、损坏；进行中或意外中断、未写最终元数据的记录没有最终成功判定。
6. 物理暂停且策略已经结束后，点击“打开记录 / 状态查看”。v2 支持滑块跳帧、播放／暂停和关闭；以记录时间推进显示，最高约 10 Hz，必要时跳过显示帧。v1 只展示原始结果，并明确提示缺少逐帧全场景状态。损坏／不完整记录不能进入场景查看，原文件保留供检查。

所有新增用户界面继续支持 English／中文切换。切换不重启后端，不改变输入、执行或原始任务文字。首次打开 v2 需要验证和建立独立渲染资源，有等待提示。

## 记录和回放的准确语义

新记录 schema 为 `robolab.p2_episode.v2`，保留 v1 原有轨迹及结果字段，增加：

- `model.xml`，XML SHA256、模型维度、MuJoCo 版本、引用的本地资产 SHA256；
- 每帧全场景 `qpos/qvel/act/ctrl`、mocap、userdata、warm start 和外部施力数组，仿真时间沿用该行 `sim_time`；
- 明确的 `sampled_scene_state_v1` 语义及原始 RGB／求解器快照缺失标记。

读取最终记录时校验 schema、样本数、轨迹哈希、索引／时间、数值和 v2 状态数组／XML；构建状态查看时进一步验证版本、资产哈希和实际模型维度。不会改写旧记录，也不会因为状态画面看似成功而改变原始判定。成功必须来自正常结束且接触、提升、官方结果全部为真；取消优先保持取消。

查看器使用独立 `MjModel/MjData/Renderer` 恢复采样状态并调用 `mj_forward` 重建画面，**不调用 `mj_step`、不执行策略、不重新判定任务成功**。编辑器的物体、关节目标、重置基准和仿真时间保持独立。画面为重新渲染的 RGB，并非录制时的原始双 RGB。该模式不是确定性的物理重执行，不是包含求解器内部状态的完整物理回放，也不是已验收的训练数据集。

v2 仍依赖原机本地 LIBERO 资产路径及匹配版本；未打包资产，不支持直接迁移到路径不同的机器后自动解析。v1 无法补出未记录的物体运动，不能将其机械臂轨迹解释为全场景回放。

点动只验证运动学可达性、关节限制及求解残差，不提供避障规划。编辑态是姿态编辑；物理态可能受碰撞阻挡。当前仍仅验证 LIBERO Panda，真实 Panda FER／D455／夹爪均未接入。

以上 5 次都为正常规则运行，没有物理抓取失败；覆盖同一汤罐任务的 **4 个官方初态**。seed 0／1 且初态同为 0 时，初始 qpos 完全相同，不能计作两个不同布局。这是少量选定初态检查，不是随机抽样成功率、任意物体／任务泛化结论。默认新记录的最终 qpos 与已有真实 v1 成功基线最大差为 **0**。

所有完整轨迹时间严格递增，哈希和执行器范围校验通过，关节目标最大变化率约 0.6 rad/s。每条约 7 MB。每条检查首／中／末状态恢复；`mj_forward` 会归一化四元数，最大 qpos 差约 `2.22e-16`，在 `1e-12` 容差内。

首轮验证曾使用逐位相等断言，因此被上述机器精度差异中断。真实已完成的抓取轨迹保留，调整容差后通过 `--resume` 复核相同源码的已结束记录并继续剩余初态，未将断言问题记为物理失败，也没有删除失败证据。详见 `outputs/p2_batch2/verification-failure.json`。

功能及桌面验收通过：

- 六方向 5 mm 编辑态点动，末端位移误差 ≤0.25 mm，朝向误差在求解容差内；物体 qpos 保持不变，重置恢复最近编辑基准。
- 真实 PD 点动到达 1 mm 内；非法坐标系／步长、不可达目标和验证进程中临时锁定的关节限位均被原子拒绝。锁定限位是标明用途的验证注入，未修改模型资产。
- 正在执行或已暂停的策略均拒绝手动点动，取消形成独立 cancelled 记录。
- 独立 v2 查看不改变包含额外编辑器物体的当前布局、qpos／qvel／ctrl、目标、重置基准、模式或时间；关闭后编辑器可继续渲染和物理单步。

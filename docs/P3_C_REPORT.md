# P3 C 批实时与历史接触查看

2026-11-10。实际开发与运行位于 WSL `/home/openvla/projects/robolab-studio`，延续本地 P2 第二批与 P3-A/B。

## 操作

1. 在「三维场景」勾选「P3 实时接触预览」。启动物理或按「单步 +20ms」后可查看标记。筛选目标、环境与干扰物、指垫或所有手指接触。点与法向的橙、蓝分别对应指 1、指 2，夹爪 XYZ 轴为红绿蓝。
2. 勾选「力箭头」可查看承载接触对另一接触体施加的模拟力。紫色长度按 3 mm/N 缩放，70 mm 封顶。读数是当前筛选中的最大单点法向力，单位 N。
3. 在「策略 / 自检」勾选「同时保存 P3 接触记录」后启动默认汤罐的 P2 规则抓取。后端在没有采样器时为该目标启用原生采样，正常结束或主动取消均可查记录。预览开关控制显示，保存由抓取前的独立选项决定。
4. 在「P2 记录 / 状态查看」打开带已校验 P3 帧的记录。勾选「P3 接触采样状态」，用滑块查任意帧，可切换桌面相机、腕部相机及半透明近景。近景仅将夹爪和目标的显示几何体变透明。关闭接触视图可切回原 P2 积分后状态。初始行没有求解器样本，旧记录或 0 帧记录保持原查看能力。

```bash
cd /home/openvla/projects/robolab-studio

bash scripts/launch.sh --p3c-test --output-dir outputs/p3c_check
bash scripts/launch.sh --p3c-gui-test --matrix-dir outputs/p3c_check --output-dir outputs/p3c_gui_check
```

## 时序与范围

实时视口在样本可用时用独立的 `MjData` 重建求解器输入姿态。历史接触查看也使用与 P2 积分后重建分开的 `MjData`。运动学、质心坐标和相机变换重建使用 MuJoCo 的 `mj_kinematics`、`mj_comPos` 和 `mj_camlight`。点、法向和力读取原始样本。视口随画面发送同一采样的显示元数据。历史的 P2 行号不变，界面同时显示求解器时刻和积分后时刻。 [MuJoCo 2.3.7 API](https://mujoco.readthedocs.io/en/2.3.7/APIreference/APIfunctions.html#mj-kinematics)

历史两相机用正方形视口重建，几何标记有真实遮挡。半透明近景用于检查被表面遮挡的接触。显示最多绘制 64 点，保留原始接触计数、过滤和记录频率。实时 RGB 标签页仍查看当前仿真场景，历史画面是重建图像。P3 仍只在原生 Euler PD 路径有原始接触样本，Mock 经官方 OSC 后提示不可用。按原设计，50 Hz 尾子步采样可能漏掉更短接触。

同一初态切换 seed 的初始 `qpos` 哈希相同，实际覆盖四个官方初态。五条记录均属同一个汤罐任务，未观察到本组的物理抓取失败。C 批仍未主动构造碰桌或干扰物的动作，环境筛选验证使用真实目标帧和结果为空的筛选对照。

- 默认实时双指样本在 7.078 s，积分后为 7.080 s。重建的夹爪 site 和双相机外参核对通过，实时 `qpos/qvel/ctrl/qacc_warmstart` 和时间逐项相同。
- 历史第 627 行的接触图来自求解器 12.538 s，原 P2 行为 12.540 s。三视角重建、初始行缺失语义、切回 P2 及实时状态隔离均通过。首轮测试发现复用 P2 数据会保留此前的求解器缓存，改用单独数据后通过，首轮结果保留。
- 36 项后端和 7 项本地化测试通过。真实 WSLg 验证启用预览、暂停、单步、重新播放、筛选、P3 落盘、取消、历史相机、双语、旧 v1/v2、切换任务与关闭后端。2 步 Mock 经 OSC 真实执行并报告 P3 原始接触不可用，双 RGB 预览回归通过。
- 单机观测的控制步中位耗时约 3.9–4.5 ms，P95 约 6.3–11.4 ms。默认姿态 12 次视口渲染的中位耗时分别约 22.7 ms（无叠加）和 58.0 ms（有叠加）。这是一次本机观测，渲染与控制分别测量。每条 P3 轨迹约 10.57 MB。

证据在 `outputs/p3c_acceptance/` 和 `outputs/p3c_gui_final_layout/`。P3-B 读写回归见 `outputs/p3c_p3b_regression/result.json`。首轮后端结果在 `outputs/p3c_verification/result.json`。

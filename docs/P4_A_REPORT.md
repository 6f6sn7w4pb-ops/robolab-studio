# P4 A 批双部位抓取与同步采集

2026-11-10。实际运行于 WSL 的 `/home/openvla/projects/robolab-studio`。

## 使用

启动 RoboLab Studio，进入「P4 部位抓取」。选择粗端或细端指令，再点「运行 P4 部位抓取」。结果分别显示指定部位、实际持续夹持部位、最大提升和双 RGB 对数。图上白十字标记指定部位中心，橙蓝标记左右指垫接触的投影。可从「打开结果目录」检查原文件。

P4 在独立 EGL 子进程运行，当前编辑器保持独立。取消时保留已经写入的样本，未结束的文件也留作排查。

```bash
cd /home/openvla/projects/robolab-studio
bash scripts/launch.sh --p4a-test --output-dir outputs/p4a_check
```

验收输出目录须为新路径。默认顺次执行粗端、细端和错部位对照。可用 `--part thick` 或 `--part thin` 只采一条。

## 场景与判定

使用现有 LIBERO Panda、地面和两台仿真相机。合成场景放置一个台阶形刚体和一个牛奶盒干扰物。台阶刚体由同色相连的两个长方体构成，默认每段长 72 mm，粗端宽／高 56／48 mm，细端宽／高 32／35 mm。两段的碰撞几何名独立。生成器支持修改限定范围内的尺寸，本轮验收使用默认参数。

两条中英文指令各映射一个部位 ID。规则教师读取该部位的仿真中心，沿稳定、接近、下降、闭合、抬起、保持阶段执行。它复用 Panda IK 和限速 PD，仿真推进时物体靠实际接触移动。部位指令由预定义映射传入，适用范围为指定合成任务。

- 部位命中要求两个指垫持续 0.20 秒各自只对同一指定部位产生承载接触，单点法向力门槛为 0.20 N。
- 提升要求两个指垫持续与目标承载接触，物体基座相对初态抬高至少 0.10 m 并连续保持至少 1 秒。
- 总通过要求指定部位本身满足持续提升条件，且采样未观察到指垫或其他手指对环境／干扰物超过上述力阈值的接触。这个检测范围是手指，50 Hz 采样也可能漏掉更短的接触。

## 数据与时序

| 文件 | 内容 |
| --- | --- |
| `manifest.json` | 中英文指令、模型和轨迹哈希、初始 qpos/qvel、部位碰撞映射、教师类型、阈值和原始结果 |
| `model.xml` | 合成场景模型，资产继续引用现有本地 LIBERO 路径 |
| `contact_trace.jsonl` | 50 Hz 求解器尾子步样本、左右指垫实际部位、物体提升、原始力及关节 PD 目标 |
| `frames.jsonl` 与 `rgb/` | 每隔 5 个接触样本存 1 对 224×224 无损 PNG，附双相机 K 和 T、指定部位中心的世界／夹爪坐标及接触点投影 |
| `projection-preview.png` | 代表帧的检查图，包含投影标记。RGB 原文件无叠加。 |

两路 RGB 都由同一个求解器输入姿态重建，保存相同 `sample_index` 和时间。重建后核对夹爪参考姿态及两台相机变换，再写文件。投影记录正深度和像素边界，遮挡可见性尚未标注。动作字段对应原生关节 PD 目标、夹爪开度和原始控制量，后续模型使用的 7 维 OSC 动作仍待转换与验证。

## 实测结果

| 指令 | 实际保持的部位 | 最大提升 | 连续有效提升 | 总判定 |
| --- | --- | --- | --- | --- |
| 粗端 | 粗端 | 16.77 cm | 2.68 s | 通过 |
| 细端 | 细端 | 16.67 cm | 2.68 s | 通过 |
| 粗端，教师被显式指向细端 | 细端 | 16.67 cm | 2.68 s | 未通过 |

三次使用相同场景 XML SHA256 与逐项相同的初始 qpos/qvel。每次为 11.1 秒物理时间、555 个接触样本、111 对双 RGB。三条记录合计 333 对、666 张 PNG，所有图像都通过重读、尺寸、时序、校准和哈希检查。验收目录约 49 MiB。错部位对照留在单独目录，命令行验收的通过状态表示它被正确判为任务失败。

独立复核粗端和细端代表帧，两路 RGB 均与同一求解器姿态重渲染结果逐像素一致。实际渲染的独立标记与 K/T 投影中心的最大偏差约 0.0714 px，验证的是这两台模拟相机的投影约定。

真实 WSLg 下通过两条指令、双语结果、主编辑器状态隔离、运行中取消与进程退出。首轮直接终止进程时只留下 `recording` 清单，已改为通过子进程输入发送取消请求。复测产生 `cancelled` 清单，保留 1 个接触样本和 1 对图像。首轮证据保留。

后端 36 项、GUI 本地化 7 项通过。原 P2 默认抓取轨迹与 P3-C 默认基线逐字节一致，真实双相机与 Mock→官方 OSC 回归通过。

完整证据位于 `outputs/p4a_acceptance/`、`outputs/p4a_gui_final/`。前者的 `result.json` 和 `pixel-check.json` 为结果摘要，后者包括桌面截图和实际取消记录。首轮桌面验收在 `outputs/p4a_gui/`。

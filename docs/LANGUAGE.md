# 中英文一键切换

更新后先关闭旧窗口，再按原方式启动 RoboLab Studio。顶部物理控制工具栏新增语言按钮：

- 当前为中文：按钮显示 **English**，点击立即切换到英文。
- 当前为英文：按钮显示 **中文**，点击立即切回中文。

不需要重新加载场景或重启软件。切换后会保存选择，下次启动沿用。偏好写在实际 WSL 项目的 `settings/ui.ini`，该文件已忽略，不随源码版本管理；它不修改 LIBERO 或 Python 环境。

## 覆盖范围与数据保护

中英文覆盖窗口标题、菜单、按钮、页签、输入提示、工具提示、属性表单、关节/末端显示、仿真/策略状态、双相机说明，以及 P1 的进度、结果和 GIF 播放控件。Qt 自带对话框使用现有 PySide6 附带的中文翻译资源，未下载语言包。

LIBERO 原始任务指令、任务和物体标识符、用户输入、模型地址、文件路径、数值、动作及观察协议保持原样。界面语言不改变模型将来接收的指令。原始后端日志、异常堆栈和导出 metadata 保留原文；已知错误的界面摘要可切换，未登记的第三方错误保留原始信息。

语言切换不会重建控件、重启后端、重置物理时间或向机器人发送控制动作。未提交的属性输入、当前对象、下拉框内部 ID、正在进行的 P1 进程和 GIF 播放状态均应保留。

## 实现与配置

- `robolab/i18n.py`：语言管理、控件绑定、已知动态消息模板、Qt 对话框翻译及偏好保存。更新下拉框/页签文字时阻断信号，避免误发控制请求；已删除的属性控件会安全移除绑定。
- `robolab/locales/en.json`：中文源文到英文的本地词典；使用原始占位符，数值格式不变。无需联网或模型。
- `gui.py`、`p1_panel.py`：将静态/动态界面文字接入绑定；原场景、相机及自检流程不变。
- `pyproject.toml` 将词典纳入包资源；没有新增或升级依赖。

可用 `ROBOLAB_UI_SETTINGS` 指定偏好文件，用 `ROBOLAB_UI_LANGUAGE=zh/en` 覆盖启动语言。一般用户直接使用顶部按钮即可，不需要配置环境变量。保存偏好失败时，当前窗口仍可切换，并显示保存失败提示。

## 测试

轻量单元测试使用既有 GUI 虚拟环境，运行 `python -m unittest discover -s tests -p test_i18n.py -v`；需在项目目录、GUI venv 中执行，测试环境可设置 `QT_QPA_PLATFORM=offscreen`。

原有后端环境未安装 Qt：使用后端执行测试发现时，本模块会明确跳过，保留原有依赖隔离，不要求向后端安装 PySide6。该跳过路径也已实际检查，退出码 0。

真实桌面测试入口为 `bash scripts/launch.sh --language-test`。测试使用独立的 `outputs/language_gui_test/preferences.ini`，不改用户偏好；检查中英文往返、独立新进程读取偏好、未提交编辑值保留、物理运行及实时相机、运行中的真实 EGL 自检、GIF 和失败提示。

测试记录在 `evidence/language-gui-result.json`，截图为 `evidence/studio-language-*.png`；实际 P1 结果位于 `outputs/language_gui_test/runs/`。本轮仅增加界面语言功能，不代表 P2 抓取或真实 VLA 推理已通过。

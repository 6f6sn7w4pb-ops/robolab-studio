# GitHub 发布与迁移验收

日期：2026-11-02。目标仓库：[6f6sn7w4pb-ops/robolab-studio](https://github.com/6f6sn7w4pb-ops/robolab-studio)。安装入口见 [INSTALL.md](INSTALL.md)。

## 本批变更

- 以 `settings/runtime.json` 或环境变量配置后端 Python、LIBERO、LIBERO 配置目录和 OFT 源码位置；移除业务代码中的原机固定用户名和 Windows 缓存路径。
- 提供只读 `--doctor` 路径/依赖导入/默认任务资源检查；普通 GUI 启动前执行检查。原机固定哈希检查保留为 `--baseline-doctor`。
- 提供项目独立配置生成工具，不覆盖已有配置或用户全局 LIBERO 配置。
- 提供复用既有后端、以及新机器显式建立 `.venv-sim` 的两条安装路线。GUI 仍单独使用 `.venv`，大模型服务独立。
- Linux 自动选择 Wayland/X11；Windows 启动器支持发行版、用户和 Linux 项目路径覆盖。
- 增加轻量 GitHub Actions 检查、Git 忽略规则及文本换行规则。仅发布平台源码、脚本和开发文档；本机设置、环境、模型、日志、实验输出及原始毕设交接资料留在本地。
- 修复首次下载后 P2 桌面测试缺少 `evidence/` 导致报告保存失败的问题；显式创建目录，同时保留空目录占位文件。

## 尚未验证与下一步

- 实验室机器的驱动、EGL、Qt 系统库以及完整的新环境安装仍须实际验收。CPU PyTorch 安装路线未在干净机器上运行，依赖约束不是所有传递依赖的完整 lockfile。
- 无桌面的 SSH 可以执行 P1；桌面 GUI 需要 WSLg、Linux 桌面或远程桌面。X11 自动选择路径尚未做真实桌面验证。
- 原机 OpenVLA-OFT 的 protobuf 导入故障仍保留；没有真实 VLA 推理、训练或真实 FER/D455 接入。
- GitHub Actions 只运行轻量合同检查，不创建物理渲染器，不代表 P1/P2 或模型验证通过。
- 实验室先执行 `--doctor`，再执行 P1 和桌面自检；通过后再接研究模型。后续功能仍按 [开发路线](LAPTOP_ROADMAP.md) 推进。

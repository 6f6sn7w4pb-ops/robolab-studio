## A 批

- A1：运行时检查 MuJoCo 版本、积分器、dt、na 和实际机器人 site；缺少映射时返回不支持，不猜名称。
- A2：确认两指 pad geom 的局部／世界空间、轴方向及目标碰撞子树，保存 profile 哈希。实际接触不能靠 contype 单项筛掉。
- A3：实现独立点／向量转换、接触 frame 旋转、geom1/geom2 反号以及有限数和刚体矩阵检查。
- A4：在 `apply_control → mj_step` 的控制尾子步加只读采样，保留 pre-step 输入状态；任何缓存数组都复制，不跨步保留可变视图。
- A5：不支持的执行路径明确报告；Mock/OFT 外部环境复制回来的 forward 结果不冒充原始力。
- A6：运行当前汤罐 seed 0 / 官方初态 0 的真实抓取，生成检查摘要；与采样关闭的同源码、同初态对照。

### A 批必要检查

| 类型 | 场景／检查 | 期望 |
| --- | --- | --- |
| 数值 | 平移、90° 旋转、随机刚体变换及往返 | 点含平移，向量不含平移；位置往返误差 ≤1e-9 m，法向单位误差 ≤1e-8 |
| 方向 | 上下球体交换 geom 顺序 | 1 kg 静态负载受力向上，误差门槛先设 0.01 N；需说明为独立场景 |
| 候选 | margin/gap 内、没有 efc 的接触 | 候选存在、约束不激活、零力，不能报告承载 |
| 身份 | 指垫／其他手指、目标／桌面／其他物体 | 分类正确，不把障碍接触计为目标接触 |
| 时序 | 20 ms 周期、2 ms 子步，暂停和单步 | 保留尾子步源时间，暂停不增帧，单步增一帧 |
| 空状态 | 无接触、未采样、失效、能力不支持 | 空列表仅表示已采样无接触，其余有独立状态 |
| 真实回归 | P3 开／关对照 | P2 判定、控制步数一致，最终 qpos 最大差 ≤1e-9，执行器及限速边界保持 |

本表为原设计门槛。已完成的默认任务检查及边界以 A 批报告为准；其他任务、主动环境碰撞动作和 GUI 尚未验收。

## B 批

- B1：落实 manifest，区分 P3 写入完整性与 P2 任务成败，最终原子更新样本数、时间、哈希与父轨迹关联。
- B2：实现 JSONL 写入、空列表、有限数拒绝和异常关闭；启用采集后写入失败须暂停并保留证据。
- B3：读取现有真正 v1/v2 记录应显示未采集，不重算补标签；sidecar 缺失、未完成、哈希错误和父轨迹不匹配分别处理。
- B4：至少完成一次正常抓取、一次实际未抓住对照和一次取消；中断／损坏为明确命名的读取测试夹具，分开统计。
- B5：核对示例合同和实际数据，冻结正式 v1；草案变动记录决定，不把设计例子混入输出 episode。

## C 批

- C1：现有原生 GUI 增加观察开关、目标／环境／指垫筛选、原始时间、单位和采样来源提示。
- C2：点／法向／力箭头及夹爪坐标轴；绘图状态与原始采样状态匹配。显示可降采样，记录频率不随 GUI 改变。
- C3：历史记录切换到原始“接触采样状态”绘制标签，避免无提示叠加到 P2 积分后状态；绝不拿回放重算力替代原记录。
- C4：真实桌面验证暂停、单步、取消、切换任务、旧记录、中英切换、关闭清理；保留截图和 JSON 结果。
- C5：同一汤罐任务复用 P2 的少量官方初态（0–3）及 seed 对照；逐项报告失败，不把相同初态换 seed 当新布局。
- C6：只做相关双 RGB／Mock 回归，明确 Mock 的 P3 原始力当前不支持；不因能力提示而破坏原 Mock 动作链路。

## G³VLA 的方法与可借鉴内容

### 论文事实

1. 几何模块位于视觉 token 通路，保持原策略的动作表示和原动作学习目标。它不是直接输出指尖接触位置的抓取模型。
2. 三个关键组成：基于相机内参 K⁻¹ 的射线嵌入、PRoPE 投影位置编码、双向跨视角融合。正文第 3 页规定射线嵌入加入 SigLIP patch embedding 后、进入 Transformer 编码器前；随后做视图内及跨视图处理。
3. 输入包含每视图 RGB、内参和相机位姿。固定外部相机外参保持固定；腕部等移动相机每次观测更新外参。相机统一采用 OpenCV 的 x 向右、y 向下、z 向前约定。裁剪、缩放或旋转必须与相机模型和监督目标同步。
4. 辅助几何头预测相机坐标系中的射线坐标与 log-z。训练监督可来自模拟器真值深度，或离线 π³X 教师。教师监督带置信度门控；论文默认阈值为 0.1。π³X 目标的 z 保留教师尺度，不能直接当成已校准的米制夹爪接触位置。
5. Stage 1 冻结预训练主干，训练射线嵌入、融合模块与辅助头；Stage 2 解冻全部参数，以动作损失为主、几何损失为正则。部署时移除辅助头，也不调用教师；相机几何模块继续工作。
6. 该本地 v2 中，VGGT 出现在相关工作中；使用的离线教师是 π³X。“冻结 VGGT 在线特征融合”可以另作研究方案，但不能称为这版 G³VLA 的原始实现。

### 实验支持的范围

- 主要实验基于 π₀，另外在 π₀.₅、GR00T 1.5 上验证迁移。第 7 页 Table IX 的 π₀.₅ LIBERO 宏平均为基线 95.9%、G³VLA 97.0%，属于论文结果，不是本项目结果。
- 第 5–6 页相机位移实验使用 16 个训练视点和 8 个留出视点，同时保持演示集规模。对 π₀，ID 平均从 86.1% 到 89.1%，OOD 从 80.6% 到 87.0%。它直接支持视点泛化分析，不能替代我们针对未见物体和指定抓取部位的实验。
- 第 7 页 Table VII 比较正确标定、轻微扰动、随机标定；消融分别去掉 ray、PRoPE 和两阶段训练。该对照方式适合借鉴，用于区分几何信息贡献与增加参数量的贡献。
- 第 7 页报告 Stage 1 使用 4 张 H200，峰值约 19.4 GB/卡。这是特定实验配置，不是任意实现的最低显存要求；不能将论文参数增量较小解释为整套训练适合 8 GB 笔记本。

## π₀.₅ 的方法与可借鉴内容

### 论文事实

1. 基于 π₀ / PaliGemma，结合视觉、语言和机器人本体状态；连续动作由 flow-matching action expert 生成。第 19 页描述的 action expert 约 300M 参数，动作段长度为 50。
2. 原论文训练配方包含异构机器人数据、网页视觉语言任务、高层子任务预测等。预训练阶段使用 FAST 离散动作；后训练加入连续动作专家，并联合文本与动作目标。其两阶段训练含义与 G³VLA 的几何预热／全策略微调不同。
3. 同一模型可先预测高层子任务，再据此产生低层动作。对我们的单次部位抓取，是否需要显式高层规划应作为范围与实验选择，不能默认必须复现整套家庭任务层级。
4. 第 19 页 Fig. 18 给出注意力掩码：action expert 能读取视觉、提示与状态前缀；前缀 token 不读取 action expert；FAST 与连续动作分支有防止表示泄漏的限制。它不等于“所有分支随意拼接即可”，也不能仅凭掩码推断参数冻结或梯度截断策略。
5. 原文动作数据包含关节及末端目标位姿，使用控制模式提示，并按各数据集各维的 1%/99% 分位数归一化。论文不规定所有接入模型都使用 RoboLab 当前的 7 维 LIBERO OSC 增量，或 OFT 当前的 8 维 proprio。
6. 原文在附录使用裁剪、缩放、旋转和颜色增强；与 G³VLA 的标定几何模块结合时，不能照搬图像变换却保持 K / 射线 / 几何标签不变。
7. 原文使用约 400 小时移动操作真实数据，另有更多其他机器人和网页数据。它不是仅靠仿真从零训练的模型。我们的迁移目标可以定义为不新增任务专用真机示教；不能据此声称基础模型没有使用过真实机器人数据。

### 实验支持的范围

- 论文研究新环境、多阶段家庭任务以及语言遵循，比较数据来源、训练环境数量和高层推理方式。
- 第 8–10 页的数据与对照实验强调控制样本预算及训练条件；第 18 页区分语言遵循与完整任务成功，并分别讨论已见类别的新实例及未见类别。
- “选对语言指定的对象”与我们拟研究的“在同一对象上抓对指定部位”是不同评价任务，后者需要额外部位标签和评价规则。

| 候选动作或抓取评分 | 本项目待验证扩展 | 检查接触与指定部位、碰撞风险、可达性是否能改善候选选择，单独做消融 |

### 近期 P3 的具体影响

1. 接触标签采用模型无关的原始记录：接触对象、手指身份、世界位置、法向与力，以及对应的夹爪参考系与位姿。力先用于标签核验和稳定性分析，是否预测力留待独立设计。
2. 保留相机内参、每帧外参、图像分辨率、图像变换及时间关联。相机射线属于相机模型，接触监督属于夹爪参考系，两者通过明确的坐标变换衔接。
3. P3 先完成当前物理时刻的真实接触采集；训练前再定义预测目标究竟是当前接触、未来动作段接触，还是候选动作条件下的接触。若预测未来接触，要规定参考坐标系的时刻和预测时域，不能只用已有接触帧代替未来抓取监督。
4. 不要求当前 P3 就录制完整几何训练集。P4 再补同步双 RGB、部位标签与可选的仿真深度。模拟深度可以仅作监督真值；真实 D455 仍按仅 RGB 输入设计。
5. 优先用仿真真值验证几何与接触学习链路，避免一开始同时引入大型离线教师、尺度误差和标签误差。是否使用 π³X 或 VGGT，等实际资源和监督需求明确后选择。
6. 新模型 Adapter 应明确状态维度、关节顺序、夹爪单位、动作空间及归一化，避免将 OFT 预处理固定到 GUI 或原始数据合同中。

### 后续可比较的实验

- A：相同数据预算的 π₀.₅ 基线。
- B：基线 + 相机几何模块。
- C：基线 + 夹爪接触监督。
- D：相机几何 + 夹爪接触监督；候选评分作为单独可切换项。

优先分别报告未见物体、指定部位命中和抓取成功，再增加相机视点变化、标定扰动与杂乱场景。固定训练／测试对象划分、可比较的训练预算、执行器及成功标准。不能将本机已有规则抓取通过率解释为上述模型结果。

## 当前结论与下一步

两篇论文提供了可组合的几何通路和动作主干，但都没有直接给出本项目的语言条件夹爪接触预测模块。近期顺序仍为 P3 接触真值及坐标验证，随后 P4 数据闭环；实验室并行核实 π₀.₅ 实际 checkpoint 和代码接口。模型接入时需另行核对所用 openpi 版本，论文说明不代替代码兼容性验证。
